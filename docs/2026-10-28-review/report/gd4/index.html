  • Migration chạy theo thứ tự: 20261028110000_welcome30_new_customer_only (đổi cờ mã WELCOME30), 20261028120000_tier_drop_notice (thêm cột rỗng được users.tierDropNoticeFor), 20261028130000_affiliate_auto_wallet_transfer (thêm dữ liệu cấu hình và mẫu tin).

  • Ảnh: thêm IMAGE_CACHE_MAX_MB=200 vào .env PROD và kiểm df -h. Thử docker build image API vì có thư viện sharp mới. IMAGE_CACHE_DIR và IMAGE_RESIZE_EXTRA_HOSTS để mặc định.
  • Không đụng PR #39 (Pancake tags). Đơn thử TUBUSUB7659607093 vẫn là điều kiện của PR đó.
